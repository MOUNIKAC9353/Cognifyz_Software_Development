# Level 2 - Task 4: Temperature Converter

## Cognifyz Technologies Software Development Internship

### Objective

Build a temperature converter program that allows users to enter a temperature and choose the conversion direction between Celsius and Fahrenheit.

### Features

- Celsius to Fahrenheit conversion
- Fahrenheit to Celsius conversion
- User input validation
- Interactive console application
- Browser-based version
- Responsive user interface
- Clear/reset functionality

### Conversion Formulas

Celsius to Fahrenheit:

F = (C × 9/5) + 32

Fahrenheit to Celsius:

C = (F - 32) × 5/9
