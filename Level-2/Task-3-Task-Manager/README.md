# Level 2 - Task 3: Task Manager CRUD Application

## Cognifyz Technologies Software Development Internship

### Objective

Create a console application for basic CRUD operations on a list of tasks.

### CRUD Operations

- Create new tasks
- Read and display tasks
- Update task details
- Delete tasks

### Task Attributes

Each task contains:

- Task ID
- Title
- Description
- Status

### Technologies Used

- Java
- ArrayList
- Scanner
- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

### Java Implementation

The console application uses an ArrayList to store tasks and implements Create, Read, Update and Delete operations.

### Browser Version

An interactive browser-based version was also developed to demonstrate the CRUD functionality through a user-friendly interface.

### Learning Outcomes

- Object-oriented programming
- Java classes and objects
- ArrayList collection
- CRUD operations
- User input handling
- JavaScript DOM manipulation
- Responsive web design
- Git and GitHub
- Deployment using GitHub Pages
