# Task 1 - Number Guessing Game

## Objective
Develop a basic text-based game using conditional statements for game logic.

## Game Description
This project is a console-based Number Guessing Game developed using Java.

The computer randomly selects a number between 1 and 100. The player gets 7 attempts to guess the correct number.

The program provides hints after each guess:
- Too low
- Too high
- Correct guess

The player can also choose whether to play the game again.

## Technologies Used
- Java
- Scanner
- Random
- Conditional Statements
- Loops

## Features
- Random number generation
- User input
- Guess validation
- High/low hints
- Attempt tracking
- Replay option
- Invalid input handling

## How to Run

Compile the program:

```bash
javac NumberGuessingGame.java
